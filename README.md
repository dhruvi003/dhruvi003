### 🚀 Featured Projects

#### 🔬 [GPT-2 Style Model — From Scratch](https://github.com/dhruvi003)
> *PyTorch · Tiktoken · Deep Learning · 2025*

Implemented a full GPT-2 style transformer in PyTorch — 50K vocab, 1024 context length, 12 attention heads. Built every component from scratch: token & positional embeddings, layer norm, GeLU, multi-head self-attention, and autoregressive text generation with temperature + top-k sampling.

#### 🤖 [Agentic RAG System with Self-Correcting Query Pipeline](https://github.com/dhruvi003)
> *LangGraph · LangChain · FAISS · RAGAS · FastAPI · Streamlit*

Architected a 4-node LangGraph agent graph (Planner → Retriever → Critic → Synthesizer) with conditional retry edges. Built a hybrid retrieval pipeline using FAISS + HuggingFace MiniLM + Cross-Encoder reranking, evaluated with RAGAS metrics, and deployed with a Streamlit frontend featuring per-query latency dashboards and full agent trace UI.
